# SPWallet

Клиентский мод для Fabric, который позволяет управлять платёжными картами СП/СПм прямо в Minecraft:
смотреть баланс, переводить АР и добавлять карты, не выходя из игры.

SPWallet продолжает мод **SPWorlds Pay** авторства **MeiNanziiii** (Miracle-Studio) и Furrc

## Требования

| | |
|---|---|
| Minecraft | 1.21.11 |
| Fabric Loader | 0.18.0+ |
| Fabric API | 0.141.0+ |
| [owo-lib](https://modrinth.com/mod/owo-lib) | 0.13.0+, устанавливается отдельно |
| [YACL](https://modrinth.com/mod/yacl) | 3.8.2, входит в jar |
| [Mod Menu](https://modrinth.com/mod/modmenu) | необязательно, для экрана настроек |

## Что умеет

* **Кошелёк** — клавиша `Z` (переназначается) на серверах `sp.spworlds.ru` и `spm.spworlds.ru`.
  Слева список карт с балансом и переключатель СП/СПм, справа форма перевода.
* **Добавление карт** — когда сервер присылает в чат сообщение c API-токеном, мод предлагает
  сохранить эту карту. Повторно уже сохранённую карту не предлагает.
* **Оплата по табличкам** — Shift+ПКМ по табличке открывает кошелёк с заполненным переводом.
  Разбор — в [SignPayment](src/client/java/ru/foxanto/spwallet/util/SignPayment.java).

  Табличка с маркером в первой строке читается целиком:

  ```
  #SPW Ник 100 АР комментарий     всё в одной строке
  #SPWP                           маркер один, дальше раскладка SPWorlds Pay
  79907
  100 АР
  комментарий
  ```

  Остальные таблички разбираются **построчно, порядок строк неважен**. Каждая строка — одно из:

  | Строка | Пример |
  |---|---|
  | цель с подписью | `Карта: 79907`, `Перевод Foxanto` |
  | одна подпись | `Оплата картой:`, `Карта:` — цель тогда на другой строке |
  | сумма | `100 АР`, в том числе внутри строки: `за алмазы - 100 АР` |
  | голая цель | `79907`, `Foxanto` |
  | оформление | `==-Шоп-==`, `~~~~~` — отбрасывается |
  | всё прочее | идёт в комментарий |

  Подписи распознаются в падежах: `карта`, `карты`, `карте`, `карту`, `картой`, `карточка`,
  `счёт`, `перевод`, `переводом`, `оплата`, `ник`, плюс `card`, `account`, `transfer`, `nick`,
  `pay`. Суффикс суммы: `АР`, `AP`, `AR`.

  Поэтому работает и табличка, где подпись не помещается в строку с целью:

  ```
  Оплата
  картой:
  70701
  ```

  Табличка считается платёжной, только если у неё **есть цель** (номер из 5 цифр или корректный ник)
  **и** хотя бы одно из: маркер, подпись у цели, сумма с «АР». Иначе обычная табличка магазина была
  бы перехвачена — обработчик отменяет клик, и до сервера он не дошёл бы.

  Читаются **обе стороны** таблички, начиная с той, к которой повёрнут игрок. Это важно для висячих
  табличек: какая из сторон считается лицевой, зависит от положения игрока, и подпись часто
  оказывается на «обратной».
* **Номер карты** — показывается серым рядом с названием в списке. Клик копирует номер в буфер
  обмена. Номера берутся одним запросом к `accounts/me` на весь список.
* **Перевод по нику** — вкладка «По нику» в панели переводов. Вводите ник, жмёте «Найти», мод
  запрашивает карты игрока и даёт выбрать, на какую именно отправить. API принимает только номер
  карты, поэтому ник сначала превращается в список карт через `accounts/{ник}/cards`.
* **Shift+ПКМ по игроку** — открывает кошелёк на вкладке «По нику» с уже запущенным поиском карт
  этого игрока.
* **Клавиши** — обе настраиваются в ванильном экране «Управление», в категории **SPWallet**:

  | Действие | По умолчанию |
  |---|---|
  | Открыть кошелёк | `Z` |
  | Модификатор для ПКМ | `Left Shift` |

  Модификатор действует и на таблички, и на игроков: он не «нажимается», а проверяется как
  зажатый в момент клика. Если снять с него привязку, модификатор перестаёт требоваться и работает
  обычный ПКМ, — на сервере это чаще всего мешает, так что снимайте осознанно.

  По умолчанию модификатор висит на том же `Left Shift`, что и приседание, поэтому Minecraft
  подсветит его в списке как конфликт. Это косметика: в 1.21.11 `KeyMapping.MAP` хранит список
  привязок на клавишу, так что обе срабатывают одновременно.
* **Настройки** — через Mod Menu: все три пункта выше можно выключить.

### Режим отладки

Опция `isDebuging` в конфиге (и любой запуск через `runClient`/`runClientGameTest`) включает
[DebugData](src/client/java/ru/foxanto/spwallet/util/DebugData.java): кошелёк открывается на любом
сервере, в списке появляются выдуманные карты, а API не вызывается вообще — балансы и номера берутся
из констант. Это нужно, чтобы работать над интерфейсом без аккаунта и не дёргать живой сервер.

⚠️ В режиме отладки мод не делает **ни одного** настоящего запроса, включая переводы. Не включайте
его, если собираетесь пользоваться кошельком по-настоящему.

Карты лежат в `config/spwallet-cards.json`, настройки — в `config/spwallet.json5`. Токены карт
хранятся в открытом виде, как и в оригинале (там была незашифрованная база SQLite).

## API SPWorlds

Мод использует четыре публичных эндпоинта, описанных в
[официальной вики](https://github.com/sp-worlds/api-docs/wiki):

| | |
|---|---|
| `GET /api/public/card` | баланс карты |
| `POST /api/public/transactions` | перевод, в ответе — новый баланс карты |
| `GET /api/public/accounts/me` | свои карты с номерами, один запрос на весь список |
| `GET /api/public/accounts/{ник}/cards` | карты другого игрока, для перевода по нику |

Авторизация — заголовок `Authorization: Bearer base64(ID:TOKEN)`. На весь API действует лимит
**200 запросов в минуту**; открытие кошелька стоит один запрос на каждую сохранённую карту.

Ник игрока валидируется по `[A-Za-z0-9_]{1,16}` до отправки: на кириллицу API отвечает
`400 FST_ERR_BAD_URL`, на несуществующего игрока — `404` с телом
`{"statusCode":404,"error":…,"message":…}`.

Не используются пока: ник по Discord ID, оплата на сайте и вебхуки.
